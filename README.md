## Resume customizer

With MongoDB running on port 27017, install dependencies with `npm ci --prefix octofit-tracker/backend` and `npm ci --prefix octofit-tracker/frontend`, then start the API with `npm run dev --prefix octofit-tracker/backend` and the frontend with `npm run dev --prefix octofit-tracker/frontend`. Open `http://localhost:5173/resume`, paste a plain-text resume and job description, and select **Customize resume**.

The tool uses simple keyword matching to put up to five relevant existing lines above the original resume and lists matching and unmatched job-description terms. It does not generate or verify qualifications, understand synonyms, or guarantee a job match. Review and edit the result, and only add qualifications you actually have. The submitted text is processed for the request and is not saved by the application.
